# Label Generator Gridfinity

- `gridfinity_bin_label.scad` uses CRLF line endings. Keep them when editing, otherwise the whole file shows up as changed.
- Whenever a part, dropdown option or icon is added or changed, run `python3 tools/generate_gallery.py` and commit the updated `docs/gallery/` pictures and `README.md` with the change. The "Supported parts" section of the README is generated, never edit it by hand.
