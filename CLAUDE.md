# Label Generator Gridfinity

- Adding a part is documented in the README under "Adding a part": a dropdown entry, a row in `parts`, a line in `draw_icon()` and the icon module. Follow those four steps instead of registering a part somewhere else.
- Icon modules all take `(icon_len, width, height, vertical_offset = 2.5)` first; anything a part needs on top of that follows. Draw with `icon_len`, never with `hardware_length` directly, so the "Icon_length" setting (Fixed or Real length) keeps working. The text under the icon comes from the `text` column of `parts`, an icon module never draws it itself.
- The customizer dropdowns are parsed from the literal `// [a, b, c]` comments, both by MakerWorld and by `tools/generate_gallery.py`. Keep that exact shape.
- `gridfinity_bin_label.scad` and `gridfinity_box_label.scad` use CRLF line endings. Keep them when editing, otherwise the whole file shows up as changed.
- The "Supported parts" section of the README and the pictures in `docs/gallery/` are generated by `tools/generate_gallery.py`, never edit them by hand.
- The "Parts gallery" GitHub Action (`.github/workflows/gallery.yml`) renders the gallery on every pull request (pictures attached as an artifact) and commits the updated pictures and README on every push to main. Running the script locally is optional; it needs a recent OpenSCAD with the manifold backend so the pictures match.
- When adding a whole new dropdown category, also add it to `collect_sections()` in `tools/generate_gallery.py` so its parts show up in the gallery.
