# Label Generator Gridfinity

- `gridfinity_bin_label.scad` uses CRLF line endings. Keep them when editing, otherwise the whole file shows up as changed.
- The "Supported parts" section of the README and the pictures in `docs/gallery/` are generated by `tools/generate_gallery.py`, never edit them by hand.
- The "Parts gallery" GitHub Action (`.github/workflows/gallery.yml`) renders the gallery on every pull request (pictures attached as an artifact) and commits the updated pictures and README on every push to main. Running the script locally is optional; it needs a recent OpenSCAD with the manifold backend so the pictures match.
- When adding a dropdown category, also add it to `collect_sections()` in `tools/generate_gallery.py` so its parts show up in the gallery.
- Icons of parts with a length (bolts, standoffs, spacers, furniture) are drawn with \`icon_len\` from \`icon_length()\`, never directly with \`hardware_length\`, so the "Icon_length" setting (Fixed or Real length) works for them. Text always shows the real \`hardware_length\`. Add a fixed size for a new kind of part to \`fixed_icon_lengths\`.
